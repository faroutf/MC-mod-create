## 中文

这个仓库是 **faroutf** 对 Minecraft Mod 和数据包的尝试性开发合集。每个子目录（或分支）对应一个独立的 Mod 项目或数据包项目。

### 项目列表

| 项目 | 类型 | Minecraft 版本 | 加载器 | 简介 |
|------|------|---------------|--------|------|
| [Daily_Quests-1.21.1-neoforge](./Daily_Quests-1.21.1-neoforge) | Mod | 1.21.1 | NeoForge | 每日任务系统：每个游戏日刷新 5 类任务（战斗、合成、挖掘、农耕、畜牧），完成任意 3 类即可领取矿物与经验奖励。 |

### 维护说明

每新增一个 Mod 或数据包子项目时，请同步更新本 README 中「项目列表」的对应条目。

## English

This repository is **faroutf**'s experimental collection of Minecraft mods and datapacks. Each subdirectory (or branch) corresponds to an independent mod or datapack project.

### Projects

| Project | Type | MC Version | Loader | Description |
|---------|------|------------|--------|-------------|
| [Daily_Quests-1.21.1-neoforge](./Daily_Quests-1.21.1-neoforge) | Mod | 1.21.1 | NeoForge | A daily quest system that refreshes each game day. 5 quest categories (Combat, Crafting, Mining, Farming, Husbandry); complete any 3 to claim mineral and XP rewards. |

### Maintenance

Whenever a new mod or datapack subproject is added, update the project table above accordingly.
